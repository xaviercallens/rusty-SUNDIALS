# RC-network benchmark (Python binding)

A stiff linear ODE with an exact solution and a static cross-check, used to
validate `rusty_sundials.CvodeSolver` (BDF):

```
dV_i/dt = -(L_ii V_i + L_ib V_b)
```

on resistor networks with unit capacitances to ground (L: graph Laplacian,
i/b: interior/boundary nodes).

| Control | Reference | Threshold |
|---|---|---|
| K1 known answer | `expm(-L_ii t)` solution at t = 0.25, 1, 4, 16 tau | 1e-5 relative, max norm |
| K2 static check | steady-state boundary currents = Dirichlet-to-Neumann column (Schur complement) | 1e-6 relative |

Fixtures (`fixtures/*.json`: node coordinates, edge list, boundary nodes):

- `hyperbolic_7_3_L2.json`: layer-2 truncation of the hyperbolic {7,3} tiling, N=112, stiffness ~15
- `square_R6.json`: square-lattice disk of radius 6, N=113, stiffness ~35

On larger networks the hyperbolic stiffness stays bounded (the Dirichlet spectral
gap has a positive limit), whereas the flat one grows linearly in N. This makes
the pair a geometry-controlled stiffness benchmark.

## Run

```
pip install numpy scipy pytest
python3 examples/python/rc_network/rc_network_benchmark.py
pytest examples/python/rc_network
```

## Source

Generated by, and described in, the Track H study:
https://github.com/xaviercallens/SocrateAI-Scientific-CondensedMatterTheory
(`experiments/track_h_hyperbolic_network`: `rc_network.py`, paper §2.5–2.6, §3.6).

Not yet covered: the binding takes no analytic Jacobian. Passing `-L_ii`
would enable solver-cost studies as a function of network geometry.
